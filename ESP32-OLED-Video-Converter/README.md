# ESP32 OLED Video Converter

A web-based video processing tool to convert video files into monochrome C byte arrays compatible with **SSD1306 / SH1106 OLED** displays connected to an ESP32.

🚀 **[Buka Live Video Converter di sini!](https://triwahyu45.github.io/ESP32-OLED-Video-Converter/)**

---

## 🌟 Features

*   **Video Upload**: Drag and drop standard video files (.mp4, .mkv, etc.).
*   **Resolution Options**: Choose between 128x64 or 128x32 display formats.
*   **Threshold Settings**: Adjustable monochrome binarization slider to fine-tune image contrast.
*   **Live Preview**: Play, pause, and preview the converted video frames in real-time as it will look on the OLED screen.
*   **Code Generation**: Instantly copy generated C arrays to use in your Arduino IDE / ESP32 code.\n
